# еНорматив

Статический портал инструментов для проверки рабочих данных эколога. Сейчас доступны две задачи: структурная проверка XLSX-книги инвентаризации источников выбросов и сопоставление источников в двух XLSX. Исходные файлы обрабатываются в браузере и не отправляются на сервер.

Проект находится в ранней версии. Проверки выявляют возможные несоответствия в данных, но не дают нормативного заключения. Учебный пример синтетический; проверка на реальных обезличенных рабочих книгах ещё предстоит.

## Локальный запуск

Нужен Node.js 22.

```bash
cd web
npm ci
npm run dev
```

Откройте адрес Vite из терминала. На главной странице доступны отдельные маршруты `/tools/check/` и `/tools/compare/`. В обоих инструментах можно открыть синтетический пример; для сравнения требуется второй файл и подтверждение, что файлы относятся к одному объекту и сопоставимому состоянию.

```bash
npm test
npm run build
```

Сборка создаётся в `web/dist/`: после Vite три действующие страницы предварительно выводятся в HTML, чтобы заголовки, описания и ссылки были доступны до запуска JavaScript. GitHub Actions публикует сборку на GitHub Pages. Публичный репозиторий содержит только код сайта и синтетический пример. Локальные исследования, рабочие документы и настройки окружения исключены из Git.

Ограничения: `.xlsx` до 20 МБ, выбранные листы до 10 000 строк; `.xls`, PDF, пересчёт формул, перевод систем координат, исправление исходного XLSX и полная проверка требований приказа № 871 пока не поддерживаются.
